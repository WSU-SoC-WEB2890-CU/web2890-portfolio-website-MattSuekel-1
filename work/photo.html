overview

This is my photography portfolio website. It features a clean, minimal design to let the photos speak for themselves. The site is fully responsive and looks great on all devices, even a dark mode!

details

This was my final project for my web Advanced CSS and design classes. Originally it was thrown together with the plain html and css. Over the holidays I had some time to kill (rare for me) but I was feeling ambitious and wanted to try something new, so I had a bit of motivation. I never have dabled in react or any frameworks before so I thought this would be a good opportunity to learn something new while also improving it. Sooooo I went for overkill and used Next.js (easy set up) and tailwind then deployed to vercel. Messy for something so simple but fun.

problem

Lack of knowledge. React/next was a learning curve. Where I have never used it before it took a bit to get used to. I do like the componentization and having some logic and html in the "same place". At this time I didn't know how to interact with a database so nothing is dynamic.

what now

well for my web3200 class I am refactoring it again. I will be useing Django for the backend and templating engine. I want to make it a bit more dynamic so I can easily add new photos and projects without having to code them in every time. I originally planned/designed a blog section as well that I will include if time allows.

Web, photography, print, and design I'm in.
